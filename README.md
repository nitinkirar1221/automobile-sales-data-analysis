# Auto Sales Analysis

This is a small data analysis project based on an Auto Sales dataset.

I used Python to clean the data, check the dataset and do some basic analysis and visualization.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## What I Did

* Loaded the Auto Sales dataset using Pandas
* Checked the rows, columns and data types
* Checked for missing values
* Removed missing values where required
* Calculated total sales
* Calculated average sales
* Found the top sales records
* Checked the relationship between `PRICEEACH` and `SALES`
* Created a histogram for sales
* Used graphs to understand the data

## Some Results

* Total Sales: 9,760,221.71
* Average Sales: 3,553.05
* Correlation between PRICEEACH and SALES: 0.808287

## Files

* `sales project.ipynb` - Python notebook containing my analysis
* `Auto Sales data.csv` - Dataset used in the project

## Conclusion

This project helped me practice data cleaning, basic analysis and data visualization using Python.
